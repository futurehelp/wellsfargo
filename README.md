# Chain of Thought 2026

Native Next.js homepage modernization for Chain of Thought, the podcast about AI infrastructure, agents, and evaluation.

## Stack

- Next.js App Router
- React 19
- Framer Motion for restrained reveals and hover states
- Local fonts, images, and brand assets
- No Astro, iframe, hosted widget, or embedded UI dependency
- Responsive desktop and mobile layouts

## Run locally

```bash
npm install
npm run dev
```

Quality checks:

```bash
npm run lint
npm run typecheck
npm run build
```
